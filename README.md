# RunSpace 2026 · Lunar Link Studio

Interactive lunar surface-payload simulator: lander and 2U gimbal model, antenna radiation, link budget, control, thermal and host-interface studies.

**Website:** [Open Lunar Link Studio](https://Thitsanapat.github.io/RunSpace2026/)

- [Simulator documentation](lunar-link-studio/README.md)
- [2U packaging and power-interface study](lunar-link-studio/PAYLOAD-DESIGN.md)
- [Antenna and RF models](lunar-link-studio/ANTENNA-LAB.md)
- [Validation and limitations](lunar-link-studio/VALIDATION.md)
- [GitHub Pages deployment](lunar-link-studio/PAGES.md)

For local use, run `lunar-link-studio/START.cmd` with Node.js 22 installed. Source reference PDFs are excluded from this repository.

The lander is reconstructed from user-provided reference images. It is not provider CAD; illustrated allocations and electronic components are conceptual. Simulation results do not establish flight qualification.
